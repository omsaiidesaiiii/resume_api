Quickstart

One request, structured output

No API key, no signup. Send a PDF as multipart form data, get JSON back.

// Node.js — using FormData
const form = new FormData();
form.append("resume", fileInput.files[0]);

const res = await fetch("https://resume-api-ott9.onrender.com/api/resumes/upload", {
  method: "POST",
  body: form,
});

const data = await res.json();
console.log(data);

Under the hood

Built to actually be reliable

01

Schema-validated output

Every response is checked against a strict schema before it's returned — no half-formed or guessed fields slip through.

02

Real persistence, real caching

Identical files are recognized by content hash and served from cache — no wasted reprocessing on repeat uploads.

03

No hallucinated fields

Extraction is grounded strictly in the resume text. If a field isn't in the document, it comes back null — never invented.
